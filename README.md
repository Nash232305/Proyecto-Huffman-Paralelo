# Huffman Parallel Compressor 

Este proyecto implementa el algoritmo de compresión y descompresión de **Huffman** utilizando tres enfoques distintos para el curso de **Sistemas Operativos** del **Tecnológico de Costa Rica**.

## Estructura del Proyecto
- `/src`: Código fuente (`.c`) y cabeceras (`.h`).
- `/datos`: Libros de prueba del Project Gutenberg.
- `instalar.sh`: Script de automatización de entorno.
- `Makefile`: Configuración de compilación.

## 🚀 Instalación y Uso
Para instalar y compilar:
```bash
chmod +x instalar.sh
./instalar.sh
